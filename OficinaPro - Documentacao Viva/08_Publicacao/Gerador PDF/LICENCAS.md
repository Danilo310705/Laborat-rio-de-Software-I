# Bibliotecas incorporadas

O gerador mantém cópias locais das bibliotecas de apresentação para funcionar sem internet durante a publicação.

| Biblioteca | Versão | Licença | Uso |
|---|---:|---|---|
| Marked | 17.0.5 | MIT | conversão de Markdown para HTML |
| Mermaid | 11.17.2 | MIT | renderização dos diagramas vivos |
| Paged.js | 0.4.3 | MIT | paginação, cabeçalhos e referências de página |

O Playwright 1.62.1, licenciado sob Apache-2.0, é utilizado externamente para produzir o PDF a partir da composição paginada.
