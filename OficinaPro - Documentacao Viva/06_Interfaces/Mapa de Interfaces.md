## Diagramas visuais da fonte

Além dos protótipos de interface, a documentação do sistema possui outros diagramas que complementam a especificação:

- Diagrama de Casos de Uso;
- Diagrama Entidade - Relacionamento;
  
Esses diagramas representam diferentes aspectos do sistema e devem permanecer consistentes com os casos de uso, regras de negócio e modelo de dados.

## Evolução recomendada

As interfaces apresentadas representam a versão atual do sistema e podem sofrer ajustes durante o desenvolvimento. Alterações futuras devem manter consistência com:

- os casos de uso;
- as regras de negócio;
- as mensagens do sistema;
- o modelo de dados;
- os requisitos funcionais.

Também devem ser considerados aspectos de usabilidade, responsividade, acessibilidade e clareza das mensagens apresentadas ao usuário.


## Contrato mínimo de uma tela

| Aspecto   | Conteúdo esperado                                             |
| --------- | ------------------------------------------------------------- |
| Objetivo  | tarefa do usuário                                             |
| Entrada   | campos, formato e obrigatoriedade                             |
| Ações     | comandos disponíveis por perfil                               |
| Estados   | normal, vazio, carregando, erro, sucesso                      |
| Regras    | Regras de negócio relacionadas à funcionalidade representada. |
| Dados     | entidades e campos exibidos                                   |
| Aceitação | cenários que cobrem a tela                                    |
