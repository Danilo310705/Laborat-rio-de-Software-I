## Evolução recomendada

- manter o arquivo-fonte editável de cada tela em `06_Interfaces/Anexos` ou usar link para a ferramenta de design;
- adicionar ao frontmatter da especificação da tela o caso de uso, estado e data de revisão;
- não usar a imagem como única definição de comportamento;
- registrar estados vazio, carregando, sucesso, validação, erro e acesso negado;
- revisar responsividade, teclado, foco, contraste e mensagens.

## Contrato mínimo de uma tela

| Aspecto | Conteúdo esperado |
|---|---|
| Objetivo | tarefa do usuário |
| Entrada | campos, formato e obrigatoriedade |
| Ações | comandos disponíveis por perfil |
| Estados | normal, vazio, carregando, erro, sucesso |
| Regras | wikilinks para RN aplicáveis |
| Dados | entidades e campos exibidos |
| Aceitação | cenários que cobrem a tela |
