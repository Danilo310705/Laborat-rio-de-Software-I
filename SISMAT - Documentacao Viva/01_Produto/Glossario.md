# Glossário

| Termo                         | Definição                                                 | Observação                                                         |
| ----------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------ |
| SISMAT                        | Sistema de Requisição de Materiais                        | Nome do produto                                                    |
| EV                            | Evento do usuário/ator ou ação externa                    | Coluna usada nos fluxos                                            |
| RS                            | Resposta do sistema                                       | Coluna usada nos fluxos                                            |
| RN                            | Regra de negócio                                          | Ex.: RN-01                                                         |
| RF                            | Requisito funcional                                       | Define o que o sistema deve fazer                                  |
| RNF                           | Requisito não funcional                                   | Define critérios de qualidade, desempenho, segurança e usabilidade |
| ADR                           | Registro de decisão de arquitetura                        | Registra como a arquitetura vai resolver                           |

> [!tip] Convenção sugerida
> Use “produto” em cadastro e dados; use “material” na linguagem do pedido. Documente qualquer exceção no contexto da tela.

> [!done] O que documentar
> **Termos com Duplo Sentido (Ambiguidade):** Palavras que possuem um significado no dia a dia, mas representam um conceito técnico ou de negócio específico no sistema. 
> - _Exemplo:_ **Caixa** (não é o operador, nem a embalagem, é o fluxo financeiro fechado).
> 

> [!error] O que não documentar
> Termos universais que qualquer usuário já conhece (ex: Botão, Login, Link, Site). Foque no que é exclusivo do negócio da empresa!
