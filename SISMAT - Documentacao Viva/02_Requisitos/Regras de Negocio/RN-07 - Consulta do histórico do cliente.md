# RN-07 - Consulta do histórico do cliente

O histórico deve apresentar somente serviços e compras vinculados ao cliente selecionado.

**Aplicação:** **Consultar histórico de serviços/compras do cliente**.

**Verificação:** utilizar o identificador do cliente para recuperar somente os registros relacionados a ele.
