# RN-15 - Relatórios com dados atualizados

Os relatórios devem considerar os dados vigentes no momento da geração.

**Aplicação:** [[UC-006 - Registrar entrada de mercadoria|UC-006]].

**Ponto de revisão:** definir tolerância de atraso se houver cache ou processamento assíncrono.
