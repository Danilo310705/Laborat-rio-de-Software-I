# RN-31 - Dados do comprovante da O.S.

O comprovante deve ser gerado utilizando os dados registrados na Ordem de Serviço, sem alterar as informações originais.

**Aplicação:** **Emitir comprovante da O.S.**

**Verificação:** utilizar os dados persistidos da O.S., cliente, veículo, produtos, serviços e valores para composição do comprovante.
